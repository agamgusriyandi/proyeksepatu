# Checklist Eksekusi: Proyek ERP Sepatu (Frontend MVP)

Berikut adalah daftar tugas untuk membangun antarmuka web progresif (PWA) berbasis React/Next.js sesuai dengan desain *wireframe* yang telah disetujui:

- [x] **Fase 1: Inisiasi Proyek & Konfigurasi**
  - [x] Melakukan inisiasi *framework* (Next.js / Vite + React).
  - [x] Mengonfigurasi Tailwind CSS untuk desain *Dark Mode* dan efek *Glassmorphism*.
  - [x] Menyiapkan variabel palet warna (Biru Elektrik, Emerald Green, Amber) dan tipografi (*Sans-serif*).
- [x] **Fase 2: Pembuatan Komponen Inti (Design System)**
  - [x] Membuat komponen *Sidebar Navigation*.
  - [x] Membuat komponen *Card Metric* (untuk Dashboard).
  - [x] Membuat komponen *Progress Timeline* (untuk status servis sepatu).
- [x] **Fase 3: Perakitan Halaman (Page Layout)**
  - [x] Merakit halaman **Dashboard** (Ringkasan order dan servis).
  - [x] Merakit halaman **Shoe Service Ticket** (Detail pengerjaan sepatu, bahan, dan foto).
- [x] **Fase 4: Uji Coba & Deployment Persiapan**
  - [x] Memastikan responsivitas tampilan (Mobile-first) agar mudah digunakan teknisi lewat HP.
  - [x] Melakukan *commit* awal (*Initial Commit*) ke GitHub.

*Status akan terus di-update seiring berjalannya proses eksekusi.*
